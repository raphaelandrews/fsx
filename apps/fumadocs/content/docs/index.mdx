Documentation for [fsx.org.br](https://www.fsx.org.br), the site of the
Federação Sergipana de Xadrez (Sergipe Chess Federation). Pick the section for
your role:

| Section | For | What it covers |
| ------- | --- | -------------- |
| [Federation guide](/guide) | Federation staff, arbiters, players | Titles, rating rules, School Games scoring, and what each page of the site shows |
| [Architecture](/architecture) | Maintainers | Domain model, request lifecycle, rendering and caching, media, authentication, contracts |
| [Reference](/reference) | Developers and LLM agents | Procedure and route catalogs, database, invariants, recipes, glossary |
| [Operations](/operations) | Whoever deploys and runs the site | Local development, backups, deployment, monitoring, incident response |
| [Decisions](/decisions) | Maintainers | Architecture decision records (ADRs) |

## Conventions

- Documentation is written in English. Portuguese appears only in proper nouns,
  routes, and quoted interface labels such as **Clássico** or **Sub 10**.
- The public site's interface is in Portuguese; the admin dashboard's is in
  English.
- When a page and the code disagree, the code is right: fix the page in the same
  change.
