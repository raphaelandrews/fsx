# Circuitos

A página de circuitos reúne os circuitos de torneios promovidos pela FSX, com
a classificação dos jogadores ao longo das etapas.

## Navegação

Abas no topo da página alternam entre os circuitos cadastrados. Cada circuito
é identificado pelo seu nome.

## Etapas e pódios

Para cada circuito, as etapas são exibidas em seções com o nome do torneio
correspondente. Cada etapa lista o pódio com a colocação, o jogador (por nome
ou apelido), a categoria e os pontos obtidos. Etapas sem resultados exibem a
mensagem "Sem resultados".
