The site is a single Cloudflare Worker that renders a TanStack Start app and
serves a tRPC API backed by a D1 (SQLite) database and an R2 image bucket.
A second Worker runs a cron cleanup of rate-limit rows.

## Packages

| Package          | Purpose |
| ---------------- | ------- |
| `apps/web`       | TanStack Start app: routes, components, SSR entry, e2e tests, and check scripts. |
| `apps/fumadocs`  | This documentation site (Astro + Fumadocs). |
| `packages/api`   | tRPC routers, cache policy, edge cache, rate limiting, media handler, security headers. |
| `packages/auth`  | Better Auth configuration and the owner-identity rules. |
| `packages/db`    | Drizzle schema, migrations, seed, and audit queries. |
| `packages/env`   | Typed access to Worker bindings and environment variables. |
| `packages/ui`    | Shared shadcn/Base UI components; no domain or database logic. |
| `packages/infra` | Alchemy resources: Worker, D1, R2, rate limiter, cron Worker. |

Dependencies point one way: `apps/web` → `@fsx/api` → `@fsx/auth`, `@fsx/db`,
`@fsx/env`. See [Architecture contracts](/architecture/contracts).
