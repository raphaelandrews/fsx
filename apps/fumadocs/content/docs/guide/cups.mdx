title: Cups

Cups are competitions organized in elimination brackets and groups, with
best-of-N matches. The Sergipe [Bullet](/guide/bullet) Championship is the cup
shown on the public site.

## Cup details

Each cup has:

- A **name** and an **image**
- **Start and end dates**
- A **prize pool**
- The **rating type** it uses (blitz, rapid, or classical)
- The **championship** it belongs to, when it is part of one

## Structure

A cup combines two structures:

- **Brackets**: upper bracket, lower bracket, and grand final. Each bracket
  has playoff phases (for example, upper-bracket semifinals), and each phase has
  best-of-N matches. A match records both players, the winner, and the games
  played, each with a link to the game.
- **Groups**: each group has players (with position and nickname) and rounds,
  whose matches use the same format as the brackets.

## Administration

Cups are created, edited, and deleted through administrative API procedures;
the admin panel has no cup screen yet. Anyone can read a single cup or the list
of cups.
