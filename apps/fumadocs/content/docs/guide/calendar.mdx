The calendar (`/calendario`) replaces the old spreadsheet. It lists the
federation's events grouped by month. It opens on **Próximos**, the next events (up to 12, from
today, even into next year). **Ano todo** shows every event of the current year, and the month
buttons narrow that year to one month. Only the current year is browsable.

Each event shows its dates, its venue (a link to a map or page when one was entered), and the same links as the home page cards
(registration, regulation, results). A link without a URL reads "em breve".
Finished events are dimmed and marked "Encerrado". An event tied to a
tournament links to its [tournament page](/guide/tournaments).

## Managing events

Events are edited under [Events](/guide/admin-panel) in the dashboard. Besides
the name and start date, an event can have an end date (for multi-day
tournaments), a venue name and/or a venue link (either one alone is enough), and an optional tournament. Link the tournament once it
has been created so the calendar entry leads to its results.
