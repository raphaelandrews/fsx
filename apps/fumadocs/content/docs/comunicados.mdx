# Comunicados

A página de comunicados reúne os comunicados oficiais publicados pela
Federação Sergipana de Xadrez.

## Lista de comunicados

Cada comunicado é exibido como uma linha com o número e o ano (por exemplo,
Comunicado 001/2026) e um resumo do conteúdo. A lista é paginada, com
navegação entre as páginas na parte inferior.

## Leitura

Clicar em um comunicado abre uma janela com o conteúdo completo.
