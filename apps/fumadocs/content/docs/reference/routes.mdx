Routes live in `apps/web/src/routes` (TanStack file routing). Public pages
are in Portuguese; the dashboard is in English.

Every public page sets a title, description, canonical URL, Open Graph tags, and
`robots: index, follow` through `buildSeo` (`apps/web/src/lib/seo.ts`), plus
breadcrumb JSON-LD. **Sitemap** marks URLs listed in `/sitemap.xml`.
`bun run check:routes` fails when a public route is missing from the sitemap.

## Private pages

All are `noindex, nofollow` and are not in the sitemap.

| URL | Purpose | Guard |
| --- | ------- | ----- |
| `/login` | GitHub sign-in | Redirects to `/dashboard` when a session exists |
| `/dashboard` and children | [Admin panel](/guide/admin-panel): list, `create`, and `$id` edit pages per entity, plus `players/titles`, `swiss-manager`, `cache`, `backup`, `user` | `_auth` `beforeLoad` redirects to `/login` without a session; data requires `adminProcedure` |
| `/rating-update` | Bulk rating import from Excel | same as `/dashboard` |

Dashboard list pages read the matching admin or public list procedure; edit
pages read `forEdit` (players, posts) or the public `byId`, and 404 on unknown IDs.

## Server endpoints

| URL | Method | Purpose | Caching |
| --- | ------ | ------- | ------- |
| `/api/trpc/<procedures>` | GET, POST | tRPC; batched procedure names are comma-separated | Public GETs at the edge per [policy](/reference/procedures); browsers get `no-store` |
| `/api/auth/*` | GET, POST | Better Auth (GitHub OAuth, session) | `no-store`; rate-limited |
| `/api/media/<key>` | GET, HEAD | R2 images | `public, max-age=31536000, immutable` |
| `/api/v1/players` | GET, OPTIONS | [Public API](/reference/public-api): active players' `id`, `name`, and ratings as JSON, CORS `*` | `public, max-age=300`; edge-cached 5 minutes |
| `/api/v1/openapi.json` | GET, OPTIONS | OpenAPI 3.1 description of `/api/v1` | `public, max-age=300`; static |
| `/api/v1/players/{id}` | GET, OPTIONS | [Public API](/reference/public-api): one active player; `404` for unknown, inactive, or malformed IDs | `public, max-age=300`; edge-cached 5 minutes, `404` included |
| `/sitemap.xml` | GET | Static pages, active players, published posts, announcements | One hour, edge and browser |
