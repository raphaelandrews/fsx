These pages are written to be scanned by people and read by coding agents:
exact names, tables, and rules rather than narrative. When code and these pages
disagree, the code wins; fix the page in the same change.

- [Procedures](/reference/procedures): every tRPC procedure with access level, input, output, cache policy, and errors.
- [Routes](/reference/routes): every URL with its data dependencies and SEO behavior.
- [Database](/reference/database): tables, constraints, indexes, and migrations.
- [Invariants](/reference/invariants): rules that must always hold and states that must never exist.
- [Recipes](/reference/recipes): step-by-step examples for common changes.
- [Glossary](/reference/glossary): domain terms and abbreviations.

The [domain model](/architecture/domain-model) explains what the data means.
