# Architecture Contracts

## Dependency Direction

`apps/web` depends on `@fsx/api`, which depends on `@fsx/auth`, `@fsx/db`, and
`@fsx/env`. `@fsx/ui` is a shared presentation library and must not import
domain or database logic.

## Procedure Access

- Public procedures return only the projections needed by the site and may be
  included in the public cache policy.
- Protected procedures require an authenticated session.
- Administrative procedures use the single-owner model and verify the configured
  identity on every request.
- Swiss Manager export is administrator-only because it combines player identity
  and birth-date data into a bulk file.
- Unknown procedures are never included in the edge cache.
- Authenticated requests, mutations, and failed/uncacheable tRPC responses use
  `Cache-Control: no-store`.

## Caching and Freshness

`packages/api/src/cache-policy.ts` is the single source of truth for cache
classification and TTLs. Mutations, errors, authenticated responses, and
unknown procedures are not cached. After an edit, the dashboard invalidates its
query families; anonymous visitors may see the previous response until the
edge TTL expires.
The Workers Cache API is data-center scoped rather than a single globally
replicated cache; measure cache-hit rates and latency before changing this model.

## D1 Migrations

Changes in `packages/db/src/schema` must generate a Drizzle migration. The
migration must be applied through the Alchemy/D1 workflow, never with `sqlite3`
directly against the local Miniflare file. The migration tracker is part of the
infrastructure state.

## Architecture Decision Records

The decisions that change security or operational behavior are recorded as
[ADRs for single-owner authorization and export access](/docs/adr-single-owner-admin),
[D1 migration ownership](/docs/adr-d1-migrations), and
[anonymous edge cache consistency](/docs/adr-edge-cache-consistency), and
[atomic D1 rating updates](/docs/adr-d1-rating-batch).
